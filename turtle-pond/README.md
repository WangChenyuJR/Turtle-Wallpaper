# 🐢 乌龟水塘 · Turtle Pond

动态桌面壁纸原型 —— 一个**侧视剖面**的小水塘：左侧一条缓坡上岸，右边水面一直铺到画面边缘，水面上方是空气。
乌龟和小鱼在里面生活。
配合 [Lively Wallpaper](https://github.com/rocksdanister/lively) 使用，即可作为 Windows 动态壁纸运行。

![预览](_shot.png)

## 功能

| 功能 | 说明 |
|------|------|
| 侧视剖面场景 | 地形由一条 `groundYAt(x)` 地表曲线描述：**只在左侧留一条缓坡上岸（右岸默认取消）**、其余全是水。**中央晒台默认取消**（阶段 8-⑧，水面不再被劈成两段）；荷叶/浮萍漂在水面上，水面上方是空气 |
| 构图 | 阶段 8-⑧ 再扩水：**水线抬到 21%、天空只留 ~10.5%、池底压到 88%（底部泥层只剩 12%）**。实测**水体面积占画面 40.8% → 44.3%**、水柱高 55% → 66.9%；左上岸缓坡横向更宽（17.2% → 19.3%）、整体坡角 23.7° → 17.1° —— 岸更好爬，水也更多 |
| 鱼群 Boids | 分离/对齐/凝聚 + **随机游走 + 漫游目标点 + 偏好水层** + 避墙 + 避光标，4 个品种（鲫鱼/锦鲤/青鱼/白鲦）。**每条鱼的感知半径/权重/游走幅度/舒适水层都不同**（由外形种子派生，读档后性格不变），邻居一多还会**主动抑制凝聚** —— 实测「≥60% 抱团」的帧占比 83% → **0%**，不再游一会儿就黏成一团 |
| 乌龟状态机 | 游动 → 追食物 → 游向最近岸线 → 爬坡上岸 → 晒太阳/爬行 → 回水。**按栖息类型分**：深水龟多在深水、半水龟两栖、陆龟基本不下水 |
| 水下碰撞 | 撞到岸坡/池底/晒台侧壁时**沿墙滑行**（只反法向、切向速度全保留 + 软避让），不再"贴墙往下滑 / 撞一下掉头"；真卡在角落会自动脱困助推。**只有游泳状态启用**，上岸/回水状态机不受影响 |
| 投喂系统 | 点击撒 10 颗饲料，**浮在水面漂流不下沉**（`food.float`），被抢食、超时溶解 |
| 选品种添加 | 点空白弹出面板：6 鱼 / 13 龟 / 6 植物，点选即投放到点击处 |
| 浮萍 | 漂浮植物，被生物推开 |
| 岸上脚印 | **侧视踩痕**：地表上一串浅浅的凹坑（踩实的暗痕 + 后缘堆土 + 坑口高光），扁到宽高比 ≈ 4:1，并顺着地形坡度躺下 —— 不再是俯视的脚掌 + 脚趾爪印 |
| 水面交互 | **一维波场**（沿 x 的高度场）：光标划过水面拉出**拖尾痕迹**（痕迹留在身后、越拖越长越淡），**不再是从一点向外扩的同心环**；光标深入水下则改成**搅动泥沙与气泡**，水面几乎不动。入水溅射是"垂直水花 + 沿水线短横痕" |
| 荷叶 | 侧视立绘：叶面几乎平铺在水线上、远端叶缘上翘，叶脉是水平浅扇形，**根茎垂到池底**；睡莲矮花 / 荷花高花；水面一荡，荷叶跟着起伏。**被生物推开要「同一水层」才算碰到**（从荷叶下面/后面经过只是投影重叠，不算撞到），推力只走水面平面内、纵向限死 3px，不会被撞得跳起来 |
| 昼夜 | 默认**跟随电脑系统时间**（04:40 天亮 / 19:40 入夜），也可切到加速循环观赏。**不画日月圆盘**，只留沿轨迹移动的柔光 + 贴着水线的地平线霞光（想恢复日轮/月轮在 Lively 里勾上） |
| 悬空吊灯 | **吊线从画面上方垂下来的一排吊灯**（1~5 盏，默认 3 盏），不落地、不需要地面，灯位只跟画面宽度有关；高斯柔光铺开一大片 + 水面光池 + 水面倒影光柱，**点哪盏亮哪盏**，I 键整组开关 |
| 生命周期与成长 | 龟寿命 24~48 小时、鱼 6~10 小时；幼体到成体肉眼可见地长大（龟 25 分钟成熟）；饿死时长以小时计，另有**寿命倍率**总开关（0.2~5×，寿命与饿死时长一起缩放） |
| 性能策略 | 页面不可见自动暂停；帧率统计 |
| Lively 属性面板 | 小鱼数/乌龟数/**寿命倍率**/浮萍密度/水色/画质/帧率显示/时间来源/日月圆盘·霞光/吊灯（开关·数量·铺开范围·悬挂高度·光照范围·模糊度·亮度） |

## 本地预览

ES Module 需要通过 HTTP 访问（直接双击 index.html 会被 CORS 拦）：

```bash
cd turtle-pond
python -m http.server 8777
# 浏览器打开 http://127.0.0.1:8777
```

## 设为桌面壁纸（Lively）

1. 打开 Lively Wallpaper
2. 把**整个 `turtle-pond` 文件夹**拖进 Lively 窗口（或点 `+ Add Wallpaper` → 选文件夹）
3. 选中它 → 壁纸生效
4. 右键壁纸 → **自定义**，可调节小鱼数量、乌龟数量、水色等（对应 `LivelyProperties.json`）

> Lively 用 WebView2 的虚拟主机映射加载本地文件，ES Module 可以正常工作。

## 操作（浏览器/壁纸通用）

| 按键 | 作用 |
|------|------|
| 左键点击 | 投喂饲料 + 弹出「选品种」面板（点面板品种 = 在点击处放 1 只，可连点） |
| 点鱼/龟 | 查看信息卡（改名/图鉴/状态） |
| 点吊灯 | 开/关**点到的那一盏**（不投喂） |
| 移动鼠标 | 鱼群避让、乌龟好奇跟随 |
| 右键 / H | 显示/隐藏帮助 |
| 空格 | 暂停/继续 |
| F | 全屏 |
| + / - | 增/减小鱼（随机品种） |
| T | 增加乌龟（随机品种） |
| A | 开关「选品种」面板（加鱼/龟/草时可选种类） |
| I | 开/关所有吊灯 |
| L / P | 物种列表 / 显示隐藏植物 |
| N | 时间快进 ×25（切到加速循环看昼夜） |
| W | 切换天气（晴 / 雨 / 雨后） |
| O / M / G | 生命档案 / 静音 / 视觉打磨开关 |
| S | 立即存档（Shift+S 导出 JSON，Shift+R 重新开始） |

## 项目结构

```
turtle-pond/
├── index.html              # 入口
├── LivelyProperties.json   # Lively 设置面板定义
├── src/
│   ├── main.js             # 主循环 + 交互 + Lively 属性接口
│   ├── config.js           # 所有可调参数集中于此（含 layout 侧视地形、life 寿命）
│   ├── world.js            # 侧视剖面地形（groundYAt 地表曲线）+ 水陆分区 + 拖尾痕迹 + 水下搅动 + 渲染
│   ├── waterwave.js        # 一维水面波场（沿 x 的高度场，波只沿水面水平传播）
│   ├── daynight.js         # 昼夜循环（默认跟随电脑系统时间）
│   ├── lamp.js             # 悬空吊灯（多盏手动照明 + 高斯柔光）
│   ├── fish.js             # 鱼群 Boids
│   ├── turtle.js           # 乌龟状态机（含栖息类型差异）
│   ├── plants.js           # 荷叶（侧视立绘，根茎垂到池底）/ 芦苇 / 水草
│   ├── duckweed.js         # 浮萍
│   ├── food.js             # 饲料系统（浮面漂流）
│   ├── scavengers.js       # 螺蛳/小虾（清道夫）
│   ├── fx.js               # 视觉打磨（景深/光斑/湿润带）
│   ├── save.js             # localStorage 存档（三份轮转 + 版本校验）
│   └── utils.js            # 数学工具
└── assets/                 # （预留）美术素材
```

## 诊断脚本（纯 Node，不开浏览器）

改动行为/几何后先跑这些，秒级完成、零 GPU 开销：

```bash
node _diag_sideview.mjs   # 侧视地形几何 + 水线高度 / 坡度 / 水体面积 / 侧视脚印 / 水陆死带（142 项）
node _diag_plants.mjs     # 荷叶侧视立绘：贴水线 / 叶缘上翘 / 根茎到池底 / 被推开的同层判定（176 项）
node _diag_wave.mjs       # 一维水面波场 + 拖尾痕迹 + 水下搅动 + 鼠标分层（41 项）
node _diag_wall.mjs       # 水下墙体碰撞：沿墙滑行 / 切向保留 / 角落脱困（21 项）
node _diag_return.mjs     # 乌龟水陆往返状态机（24 项，可传随机种子）
node _diag_lamp.mjs       # 昼夜换算 + 天光 + 悬空吊灯几何（107 项）
node _diag_panel.mjs      # 信息面板 UI 逻辑（18 项，假 DOM）
node _diag_render.mjs     # 端到端渲染链路（25 项，假 DOM）
node _diag_fish.mjs       # 鱼群 + 水陆分类自洽 + 运动随机性 + 不黏团（17 项）
node _diag_save.mjs       # 存档快照/复原 + 寿命倍率（20 项）
node _diag_body.mjs       # 生物体积碰撞：侧视图允许重叠 / 软分离 / 跨类无碰撞（14 项）
```

合计 **605 项**断言，全部秒级、纯 Node。
