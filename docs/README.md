## 每份品种资料包含

- 中英文名、学名、栖息类型、成体尺寸、适温、pH、食性、难度
- 外观特征、行为要点、饲养环境
- **对应项目 id**（与 `turtle-pond/src/species.js` 对齐）
- 壁纸设计提示（哪些特征适合做成动画/玩法）

## 数据对接

调研数据已整理为可直接运行的文件：

```
turtle-pond/src/data/species-research.js
```

包含：
- `TURTLE_RESEARCH` / `FISH_RESEARCH` —— 百科信息 + 绘制配置
- `turtleDrawConfig(id)` / `fishDrawConfig(id)` —— 取出可直接注册的配置
- `listTurtleInfo()` / `listFishInfo()` —— 百科摘要列表
- `terrapinSubSpecies()` —— 钻纹龟 7 亚种（收集系统）
- `registerResearchedInto({...})` —— 一键注册本批新品种
