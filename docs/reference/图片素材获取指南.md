# 物种图片素材获取指南

> 说明：本项目需要各龟/鱼品种的图片，用于壁纸美术参考、设置面板缩略图、以及（可选）真实感贴图。
> **本次未生成/下载图片**（用户选择先做文字资料）。本文档给出**可执行**的图片获取方案与来源清单。

---

## 1. 为什么不直接下载

本次实测：当前环境**直连下载图片被网络策略拦截**（HTTPS 到 `upload.wikimedia.org` / `commons.wikimedia.org` 握手超时）。
可访问的图床有限（`images.unsplash.com`、`raw.githubusercontent.com` 通）。

**结论**：图片建议按下面三种方式之一获取，全部**无版权风险**。

---

## 2. 方案 A：CC0 免费素材库（推荐，可商用免署名）

| 站点 | 地址 | 协议 | 说明 |
|------|------|------|------|
| Wikimedia Commons | commons.wikimedia.org | 多为 CC BY-SA / CC0 | 各物种**照片最全**，按学名搜最准 |
| iNaturalist | inaturalist.org | CC 系列（看条目） | 观察记录照片，含大量龟类 **按学名/地点筛选** |
| Pixabay | pixabay.com | 简化版 Pixabay 许可（可商用） | 通用龟鱼照片 |
| Unsplash | unsplash.com | Unsplash 许可（可商用） | 高质量但物种覆盖少 |
| Openverse | openverse.org | 聚合 CC 内容 | 一站式搜 CC 图片/音频 |

> **搜法**：优先用**学名**搜索（如 `Trachemys scripta elegans`、`Malaclemys terrapin`），比中文名准确得多。
> **署名**：CC BY / CC BY-SA 的图片必须署名 → 统一记到项目根 `CREDITS.md`。

---

## 3. 方案 B：AI 生成（风格统一、零版权风险）

若希望所有品种**风格一致**（适合壁纸美术参考、设置面板图标），用 AI 文生图最合适。

**已备好提示词模板**（见下），生成后按命名规则存入 `turtle-pond/assets/creatures/`。

### 命名规则
```
turtle-pond/assets/creatures/turtle/<id>_<view>.png
turtle-pond/assets/creatures/fish/<id>_<view>.png
```
- `<id>` 用 `species.js` 里的品种 id（如 `redear`、`yellowthroat`、`terrapinOrnate`）
- `<view>` 取 `top`（俯视，看背甲花纹）/ `side`（侧视，看头颈四肢）/ `front`（正视，可选）
- 示例：`turtle/redear_top.png`、`turtle/yellowthroat_side.png`、`fish/koi_side.png`

### 提示词模板（英文示例，可自改）

**龟（俯视，突出背甲花纹）**
```
Top-down view of a single {学名 / 中文名} turtle resting on a pond rock,
showing the full carapace pattern clearly, {花纹描述: concentric diamond rings / three longitudinal keels / golden lines along scutes},
{体色描述}, clean neutral background, soft natural daylight, photorealistic,
high detail, isolated subject, no text
```

**鱼（侧视，突出体型与色纹）**
```
Side profile of a {品种名} freshwater fish, {色纹描述: blue-white horizontal stripes / red-blue neon stripe},
{体型: slim streamlined / round-bodied with long flowing tail}, swimming,
clean light background, soft aquarium lighting, photorealistic, isolated subject, no text
```

## 4. 方案 C：自绘 / 矢量（与项目 2D 渲染最契合）

项目现在是 **Canvas 2D 矢量绘制**（无贴图依赖）。若走这条线：
- 直接用 Aseprite / LibreSprite / Krita 按 `species.js` 的配色自绘精灵图；
- 或继续用代码矢量绘制（当前路线），图片仅作**参考资料**，不进资源包。

---

## 5. 存放规范（已在项目内建好目录）

```
turtle-pond/assets/creatures/
  turtle/    ← 龟类图片（<id>_<view>.png）
  fish/      ← 鱼类图片（<id>_<view>.png）
docs/reference/   ← 本指南 + 其他参考资料
docs/species/     ← 品种文字资料（Markdown）
```

图片一旦放入，建议同步更新项目根 `CREDITS.md`（记录来源 URL、作者、协议）。

---

## 6. 版权合规红线

- ✅ 优先 **CC0**（可商用、免署名、无传染）
- ⚠️ **CC BY / CC BY-SA**：必须署名，记入 `CREDITS.md`
- ❌ 避免：来源不明的网络图、带水印素材、付费素材的免费预览版
- 📝 项目根建 `CREDITS.md`，逐条登记
