# 宠物/观赏鱼品种资料库

> 用于「桌面乌龟水塘壁纸」项目的鱼类设计参考。鱼类是水塘生态的「背景生物」，同时承担鱼群 Boids 行为、龟类捕食对象、投喂响应等玩法。
> 整理日期：2026-10-01 ｜ 数据来源：百度百科 / 快懂百科 / 各地观赏鱼资料。尺寸为常见成体范围。

> **字段说明**
> - **水层**：`上层 top`｜`中层 mid`｜`下层 bottom`（影响项目中鱼的游动带）
> - **成体体长**：常见范围（cm）
> - **适温**：适宜水温（℃）｜**pH**：适宜酸碱度
> - **对应项目 id**：`turtle-pond/src/species.js` 中的键名

## 1. 鲫鱼（crucian）

| 项目 | 内容 |
|------|------|
| **学名** | *Carassius auratus*（野生型） |
| **水层** | 中下层 |
| **成体体长** | 15–25 cm |
| **适温** | 0–32℃（极耐温，广温性） |
| **食性** | 杂食，以浮游生物、藻类、碎屑为主 |
| **行为要点** | 适应力极强、耐低氧；常成群活动 |
| **外观** | 体侧扁，银灰/金褐色，鳞片明显 |
| **项目 id** | `crucian` ｜ 主色 `#c9a227` ｜ 权重 3（常见种） |

## 2. 锦鲤（koi）

| 项目 | 内容 |
|------|------|
| **学名** | *Cyprinus carpio*（观赏选育） |
| **水层** | 中下层 |
| **成体体长** | 20–50 cm（庭院池可更大） |
| **适温** | 18–24℃ |

| **项目 id** | `koi` ｜ 主色 `#e07a3f` ｜ 体型 1.25× ｜ 权重 2 |

## 3. 青鱼（grasscarp）

| 项目 | 内容 |
|------|------|
| **学名** | *Mylopharyngodon piceus* |
| **水层** | 下层（一般不游近水面） |
| **成体体长** | 常见 60–100 cm，最大可达 190 cm / 70 kg |
| **适温** | 20–32℃（15℃ 以下停食） |
| **食性** | 肉食：喜食螺蛳，俗称「螺蛳青」；也食蚌、蚬、虾 |
| **行为要点** | 习性不活泼，栖底层多螺蛳处；行动有力 |
| **外观** | 体圆筒形，青黑色，各鳍黑，无腹棱 |
| **项目 id** | `grasscarp` ｜ 主色 `#4f7f86` ｜ 权重 2 |

> 说明：项目内 id 沿用 `grasscarp`（早期命名），实际为青鱼；若后续改名需同步 `species.js`、`DEFAULT_POPULATION` 及 Lively 配置。

## 7. 孔雀鱼（guppy）★建议新增

| 项目 | 内容 |
|------|------|
| **学名** | *Poecilia reticulata* |
| **水层** | 中上层 |
| **成体体长** | ♂ 3–4 cm，♀ 5–6 cm |
| **适温** | 22–28℃ ｜ pH 7.0–8.5 |
| **食性** | 杂食 |
| **行为要点** | 活泼好动、**胎生、繁殖力极强**；雄鱼尾鳍华丽 |
| **外观** | 尾鳍/体色变异极多（红、蓝、马赛克…） |
| **项目 id** | 建议 `guppy` ｜ 体型 0.65× ｜ 速度 1.3× ｜ 权重 3 |

> **壁纸设计提示**：孔雀鱼繁殖快，天然适合做成「鱼群会自动繁衍」的生态玩法。

## 8. 斑马鱼（zebrafish）★建议新增

| 项目 | 内容 |
|------|------|
| **学名** | *Danio rerio* |
| **水层** | 中上层 |
| **成体体长** | 4–5 cm |
| **适温** | 18–28℃（极耐寒，室温即可） |
| **食性** | 杂食 |

| **项目 id** | 建议 `zebrafish` ｜ 主色 `#5b7fbf` ｜ 速度 1.3× ｜ 权重 3 |

## 9. 泰国斗鱼（betta）★建议新增

| 项目 | 内容 |
|------|------|
| **学名** | *Betta splendens* |
| **水层** | 中上层 |
| **成体体长** | 6–7 cm |
| **适温** | 24–30℃ ｜ pH 6.5–7.5 |
| **食性** | 肉食 |
| **行为要点** | 有**迷鳃器官**可直接呼吸空气（不需打氧）；**雄性必须单养**，好斗 |

> **壁纸设计提示**：斗鱼单养+好斗可做成「会驱赶其他鱼」的特殊个体，增加行为差异。
