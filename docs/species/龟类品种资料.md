# 宠物龟品种资料库

> 用于「桌面乌龟水塘壁纸」项目的物种设计参考。
> 整理日期：2026-10-01 ｜ 数据来源：公开科普资料（百度百科 / 快懂百科 / 科普中国 / 维基 / 香港乌龟资料中心），尺寸为常见成体范围，野外个体与人工饲养存在差异。
>
> **字段说明**
> - **栖息类型**：`水龟 aquatic`（几乎不上岸）｜`半水龟 semi`（水陆两栖，白天晒背）｜`陆龟 terrestrial`（极少下水）｜`沼泽龟 marsh`（浅水泥沼，善潜泥）
> - **成体甲长**：背甲长度范围（cm），雄性/雌性常有两性异形
> - **水温**：适宜活动/进食水温（℃）
> - **对应项目 id**：`turtle-pond/src/species.js` 中的键名

## 1. 巴西红耳龟（redear）

| 项目 | 内容 |
|------|------|
| **中文名** | 巴西红耳龟 / 红耳龟 / 巴西彩龟 |
| **学名** | *Trachemys scripta elegans* |
| **栖息类型** | 半水龟（semi）—— 水陆两栖，极爱晒背 |
| **成体甲长** | 雌 20–30 cm，雄 15–25 cm（雌大于雄） |
| **适温** | 22–28℃（低于 10℃ 冬眠） |
| **寿命** | 20–40 年+ |
| **食性** | 杂食，幼体偏肉食（鱼虾/昆虫/蠕虫），成体接受水草蔬果 |
| **行为要点** | 生性活泼、有攻击性；晒背需求高；水质差易患白眼病/腐甲 |
| **外观特征** | 眼后一对**红色粗条纹**（红耳）；背甲墨绿，盾片中央黄绿斑；随龄增色变褐橄榄 |
| **饲养环境** | 水深≈龟高 2 倍；水 6 : 陆 4，配晒背台；强力过滤；UVB 灯 |
| **项目 id** | `redear` ｜ habitat `semi` ｜ 壳纹 `rings` ｜ 标记色 `#d94f3d` |

> **壁纸设计提示**：红色耳斑辨识度最高，缩小后仍是视觉焦点；晒背行为明显，适合做「爬上岸石晒太阳」动画。

## 5. 黄喉拟水龟（yellowthroat）★必选

| 项目 | 内容 |
|------|------|
| **中文名** | 黄喉拟水龟 / 石金钱 / 石龟 / 黄喉水龟 / 小头金龟 |
| **学名** | *Mauremys mutica* |
| **栖息类型** | 半水龟（semi）—— 水陆两栖，多在水中 |
| **成体甲长** | 15–21 cm（♂ 11.8–13.8，♀ 9.5–13.8 常见记录）；体重约 0.75 kg |
| **适温** | 18–32℃（最适 26–28）；10℃ 左右冬眠 |
| **食性** | 杂食，偏好鱼虾、动物内脏；亦食果皮嫩草 |
| **行为要点** | 性情温顺无异味；白天水中游、晴天上岸晒壳；胆小，受惊缩壳 |
| **外观特征** | 头背青橄榄色；**头侧眼后各一条镶黑边的淡黄色纵纹**延伸至颈；喉部淡黄故名「黄喉」；背甲棕黄，中央一条明显纵棱；腹甲浅黄具黑斑（南种黑斑大、成马蹄形；北种小，无斑者称「象牙板」） |
| **亚型** | 南石（南种）/ 大青 / 北种小青 / 三黄小青等；体色南深北浅 |
| **项目 id** | `yellowthroat` ｜ habitat `semi` ｜ 壳纹 `lines` ｜ 主色 `#7a6a3a`，标记 `#e8d24e`（喉部青黄） |

> **壁纸设计提示**：黄喉是其头号特征，渲染时头顶+喉部用淡黄渐变；是绿毛龟的正宗培育种，可作特殊养成彩蛋。

## 11. 沼泽侧颈龟（helmetedSideNeck）★必选

| 项目 | 内容 |
|------|------|
| **中文名** | 沼泽侧颈龟 / 钢盔侧颈龟 |
| **学名** | *Pelomedusa subrufa* |
| **栖息类型** | 半水龟（semi）—— 但侧颈类，头部**侧弯缩入**而非直缩 |

## 13. 钻纹龟（terrapin）★必选（含全 7 亚种）

**总述**：北美唯一生活在**咸水/半咸水**的龟；两性异形显著（♀ 体型≈♂ 2 倍）。共同特征是背甲**同心圆/钻石（钻纹）图案**与头部斑点。

| 项目 | 内容 |
|------|------|
| **中文名** | 钻纹龟 / 菱斑龟 / 金刚背泥龟 |
| **学名** | *Malaclemys terrapin* |
| **栖息类型** | 咸水半水龟（aquatic 特例，需提高水盐度） |
| **成体甲长** | ♂ 10–15 cm；♀ 19–24 cm（最大记录 24 cm） |
| **适温** | 20–28℃（最适 25）；5℃ 可自然冬眠 |
| **食性** | 肉食：贝类、蟹、虾、螺、小鱼，偶食植物 |
| **行为要点** | 活泼，有晒背习惯，抗寒力较强 |
| **保护级别** | IUCN 易危（VU） |
